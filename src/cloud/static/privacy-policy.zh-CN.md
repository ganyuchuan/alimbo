# Agent Limbo 隐私政策（中文）

最后更新日期：2026-07-22
生效日期：2026-07-22

欢迎使用 Agent Limbo（以下简称“本应用”）。本隐私政策说明 YUCHUAN GAN（以下简称“我们”）如何收集、使用、存储和保护您的个人信息。

## 1. 适用范围

本政策适用于您在 iOS 与 watchOS 上使用 Agent Limbo 相关功能时产生的信息处理活动。

## 2. 我们收集的信息

根据您使用的功能，我们可能处理以下信息：

1. 账户信息（由您授权提供）
- 登录方式（例如 Sign in with Apple）
- 显示名称
- 邮箱地址（取决于您的 Apple 授权设置）

2. 设备与应用信息
- 设备标识相关信息（例如设备型号、系统版本）
- 应用版本、构建号
- 推送通知设备令牌（APNs Device Token）

3. 配对与连接配置
- 配对码、配对状态
- 服务连接地址（Host）
- 认证令牌（Auth Token）

4. 操作与使用信息
- 审批相关操作（如 approve、deny、retry、skip）
- 最近消息摘要、状态展示信息

说明：以上部分信息可能仅保存在您的本地设备，用于功能实现和体验优化。

## 3. 我们如何使用信息

我们仅在实现产品功能所必需的范围内使用您的信息，包括：

1. 完成账户识别与跨端同步
2. 建立手表与手机/服务端配对关系
3. 提供推送通知与状态提醒
4. 支持审批流交互与历史展示
5. 进行故障排查与服务安全保障

## 4. 信息共享与披露

除以下情形外，我们不会向第三方出售您的个人信息：

1. 获得您的明确授权或同意
2. 为提供服务所必需的第三方服务商（例如 Apple 推送通知服务）
3. 为履行法律法规义务、响应司法或监管要求
4. 为保护我们或他人的合法权益与安全

## 5. 数据存储与安全

1. 我们采取合理的技术与管理措施保护数据安全。
2. 部分配置数据（如 host、token、配对状态）可能存储在设备本地，用于维持连接和使用体验。
3. 尽管我们采取安全措施，互联网传输与存储无法保证绝对安全。

## 6. 数据保留

我们仅在实现本政策所述目的所需期间保留数据，法律法规另有要求的除外。您可通过卸载应用、重置配置或联系支持来请求删除或停止使用相关数据。

## 7. 您的权利

在适用法律允许范围内，您可能享有以下权利：

1. 访问、更正您的个人信息
2. 删除您的个人信息
3. 撤回授权同意（不影响撤回前处理）
4. 关闭通知权限或停止账号同步

## 8. 儿童隐私

本应用不面向未满 13 周岁（或您所在司法辖区规定年龄）的儿童提供服务。若我们发现误收集儿童信息，将尽快删除。

## 9. 第三方服务

本应用可能接入第三方服务（例如 Apple 账号体系、Apple 推送服务）。第三方服务的数据处理受其各自隐私政策约束。

## 10. 政策更新

我们可能适时更新本政策。更新后将通过应用内或官网页面发布。若更新涉及重大变更，我们将以合理方式提示您。
