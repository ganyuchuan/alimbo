审批记录

                    

                  

                

              

            

            
          


          

            
1. 下载 iOS App

            
打开你的 iPhone 或 Apple Watch 的 App Store，搜索并下载 「AI 审判官」。

            
2. 安装与配对

            
打开 App 进行登录，登录完成后获得1个配对码，在你的电脑通过 npm 安装网关，输入该配对码完成手表与电脑 Agent 的配对。

            
3. 离开电脑，开始审批

            
完成配对后，你可以打开常用的 Agent 工具开始工作，即使离开电脑也能在 iPhone 或 Apple Watch 上进行审批操作。

          

        

      


      

        
更多功能

        

      


      

        

          

            🐈‍⬛
            
电子宠物

            
为你的 Apple Watch 带来18只独特的像素小伙伴，它们会随着你的 AI 工作状态喜怒哀乐、一起打拼。简单介绍下：

            
🌵 仙人掌 Cactus 明亮绿色的刺球，慵懒时会微微下垂，偶尔低声哼唱。

            
🐱 猫咪 Cat 同款棕色的懒散喵星人。

            
👻 幽灵 Ghost 纯白半透明的小鬼，会悄悄隐身、穿墙、再微笑着出现。

            
...

          

          

            💬
            
在飞书上对话

            
你也可以在飞书 App 上与 Agent 聊天，给它发送指令，或审批它的操作。

            
聊天同时支持「文字」、「图片」和「文件」三类消息。

            
支持 8+ 命令，你可以在飞书里远程调用常见的 SKILL、MCP、Git 等工具。

            
当 Agent 需要审批时，你也可以在飞书 App 上收到一张交互卡片去 Yes or No。

          

          

            📢
            
Push 通知

            
即使关掉 App 退到后台也不会让你错过 Agent 的任何审批请求，在它完成任务后也会及时通知到你！
