1. 工作目录

            
查看当前 Agent 正在操作的本地项目目录，确认它正在正确的工作空间中执行任务。

            
2. 当前状态

            
实时了解 Agent 是否在线、当前使用的 Agent 及版本，以及它与智能设备的配对状态。

            
3. 待审批队列

            
当 Agent 需要执行重要操作时，审批请求会进入队列。你可以在 iPhone 或 Apple Watch 上查看详情并选择允许或拒绝。

            
4. 工具调用记录

            
按时间查看 Agent 的工具调用记录，包括工具名称、执行时间、操作说明、命令内容和最终审批结果。

可操作的审批通知

            
当 Agent 正在等待关键审批时，你会第一时间收到提醒，立刻知道哪个工具、哪条命令卡住了进度，然后长按通知条即可放行让它继续操作。

            
任务完成通知

            
任务结束、Agent 下线或阶段性完成时，系统会给出结果通知，方便你及时决定是否重新安排下一段工作。

            
如何打开通知

            
首次安装后允许推送权限；如果此前关掉过，也可以在 iPhone 的“设置 - 通知 - Agent Limbo”里重新开启锁屏、横幅和声音提醒。

            
如何关闭通知

            
如果你只想在特定时段保持安静，可以在系统通知设置里关闭横幅或锁屏提醒，也可以直接彻底关闭该应用通知。
